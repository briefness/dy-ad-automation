# 故障排查

## 环境与服务

### ffmpeg 不可用

```bash
ffmpeg -version
ffprobe -version
```

macOS 使用 `brew install ffmpeg`，Ubuntu/Debian 使用 `sudo apt install ffmpeg`。建议 ffmpeg 4.0 或更高版本。

### 可灵 API 调用失败

检查以下任一鉴权组合：

- `KLING_ACCESS_KEY` + `KLING_SECRET_KEY`
- `KLING_API_KEY`

同时确认接口地址、额度、模型名和网络连接。

### 本地素材视觉分析未启用

本地素材模式要求：

```ini
VISION_ENABLED=true
VISION_API_KEY=...
VISION_BASE_URL=...
VISION_MODEL=...
```

模型必须支持兼容 OpenAI Chat Completions 的 `image_url` 输入。系统不会在缺少视觉理解时盲剪。

## 脚本合同

### 所有响应均未形成有效的完整 segments JSON

依次检查：

1. LLM 响应是否被截断或混入 Markdown 说明。
2. 模型输出长度是否足以返回完整候选。
3. 最后一条合同校验错误是否指出具体 segment。
4. 产品资料和素材证据是否足以支持脚本要求。

不要手工拼接残缺 JSON，也不要删除合同校验。生成器会将上一轮错误反馈给下一轮重试。

### Evidence Anchor 缺失或无关

具体产品主张需要相关的非名称证据。可采取：

- 补充真实的原料、产地、工艺、规格或已核验卖点；
- 提供能够清晰显示对应实体或包装文字的素材；
- 将没有购买理由的段落降为 `proof`，而不是强行写成 `value`。

### visual claim 与素材不一致

确认文案中的可见主体、动作或状态确实存在于该素材角色的 `primary_visuals`。背景偶然出现的对象不足以承载主要字幕主张。

## 选片与时间轴

### 素材中有画面，但匹配容量为 0 秒

常见原因：

- 对象只在背景或短暂闪现；
- 连续可用时间短于语义段需求；
- 同一窗口已被去重或分配给更强匹配段；
- 脚本要求的是动作/状态，而素材只显示静态主体；
- 素材理解结果与实际画面不一致。

查看失败任务保留的素材理解、生产计划和时间轴审查 JSON，定位是“理解错误”还是“匹配容量不足”。

### 指定 30 秒但成片不足 30 秒

本地素材模式不会为满足目标时长而循环、拉伸或使用无关画面。检查去重后的素材容量、转场净损耗和单条 TTS 时长。目标时长是规划偏好，不是伪造素材的强制值。

### 字幕比画面早或晚

确认当前任务没有混用旧的断点产物，并检查最终语义时间轴是否与单条 TTS cue 数量一致。默认智能时长和显式目标时长使用不同权威，但字幕、贴图和画面必须消费同一个最终时间轴。

## 贴图与音频

### 贴图没有出现

检查 `--stickers`、视频风格、当前字幕是否包含有证据的信息，以及画面是否存在安全展示区域。强制 `on` 不会绕过证据和遮挡校验。

### 口播未生成

检查豆包 TTS 配置或本机降级 TTS 是否可用。请求了口播但没有有效音频时，严格模式会阻断不可发布成片。

## 失败产物

失败任务的中间文件会保留在控制台打印的 `output/` 子目录。成功任务会清理 `final/` 中的临时渲染文件，但保留脚本、贴图计划、时间轴审查和运行清单等审计产物。
